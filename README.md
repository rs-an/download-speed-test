# Замер скорости скачивания

Консольный скрипт на Python: выполняет 10 последовательных запросов к указанному URL, полностью скачивает каждый ответ и выводит среднее время, общий объём и скорость.

## Требования

Python 3.9 или новее.

## Запуск

```bash
python3 speed_test.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

Можно указать прямую ссылку на любой доступный HTTP/HTTPS-файл. В примере используется тестовый сервер Cloudflare: 10 МБ на запрос, всего 100 МБ.

## Результат

- Среднее время запроса — в секундах.
- Общий объём — в байтах и MiB (1 MiB = 1 048 576 байт).
- Скорость — в Мбит/с: общий объём в байтах × 8 / общее время в секундах / 1 000 000.

Время включает соединение и ожидание сервера, поэтому результат зависит не только от скорости интернета.

При ошибке замер останавливается без итоговой скорости. Сетевой тайм-аут — 30 секунд; общая длительность скачивания не ограничена.
